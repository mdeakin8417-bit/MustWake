# ⏰ MustWake — সম্পূর্ণ রোডম্যাপ (A টু Z)

শুধু **ফোন** দিয়ে, **Spck Editor + GitHub** ব্যবহার করে এই অ্যাপ বানানো ও ইনস্টল করার সম্পূর্ণ গাইড। ল্যাপটপ লাগবে না।

---

## ✅ ধাপ ১: প্রয়োজনীয় অ্যাপ ইনস্টল করুন (৫ মিনিট)

Play Store থেকে ইনস্টল করুন:
1. **Spck Editor** (কোড এডিটর + GitHub সিঙ্ক)
2. একটি **GitHub অ্যাকাউন্ট** তৈরি করুন (যদি না থাকে) — [github.com](https://github.com) এ ফোনের ব্রাউজার দিয়ে সাইনআপ করুন

---

## ✅ ধাপ ২: GitHub-এ রিপোজিটরি তৈরি করুন (৩ মিনিট)

1. GitHub অ্যাপ/ব্রাউজারে লগইন করুন
2. **New Repository** চাপুন
3. নাম দিন: `smart-alarm`
4. **Public** সিলেক্ট করুন (Actions ফ্রি ব্যবহারের জন্য)
5. **Create repository** চাপুন

---

## ✅ ধাপ ৩: Spck Editor দিয়ে GitHub-এ কোড আপলোড করুন (১৫ মিনিট)

1. Spck Editor খুলুন → **Clone from Git** অপশনে যান
2. আপনার `smart-alarm` রিপোর URL দিন এবং ক্লোন করুন (GitHub টোকেন/লগইন দিয়ে অথরাইজ করতে হবে)
3. আমি যে ফাইলগুলো নিচে দিয়েছি (এই চ্যাটের ফাইল প্যাকেজ থেকে ডাউনলোড করা `smart-alarm` ফোল্ডার) — সবগুলো Spck Editor-এ **ওই একই ফোল্ডার স্ট্রাকচার বজায় রেখে** কপি-পেস্ট করুন:

```
smart-alarm/
├── config.xml
├── package.json
├── .github/workflows/build.yml
└── www/
    ├── index.html
    ├── css/style.css
    └── js/
        ├── app.js
        ├── alarm-engine.js
        └── missions.js
```

4. প্রতিটা ফাইল Spck-এ **নতুন ফাইল তৈরি করে** কনটেন্ট পেস্ট করুন (আমার দেওয়া ডাউনলোড লিংক থেকে ফাইল খুলে কপি করবেন)
5. সব ফাইল যোগ হয়ে গেলে Spck Editor-এর **Git প্যানেলে** যান → **Commit** → মেসেজ লিখুন "Initial commit" → **Push** চাপুন

➡️ কোড এখন আপনার GitHub রিপোতে চলে যাবে।

---

## ✅ ধাপ ৪: GitHub Actions অটোমেটিক APK বানাবে (১৫-২০ মিনিট, ওয়েট করতে হবে)

1. পুশ করার সাথে সাথেই `.github/workflows/build.yml` ফাইলটি অ্যাক্টিভ হয়ে যাবে
2. GitHub অ্যাপ/ব্রাউজারে আপনার রিপোতে যান → **Actions** ট্যাব
3. দেখবেন **"Build Android APK"** নামে একটা রান শুরু হয়েছে (হলুদ বৃত্ত ঘুরছে)
4. ১০-২০ মিনিট পর সবুজ ✅ চিহ্ন দেখাবে — বিল্ড সম্পন্ন
5. সেই রানে ক্লিক করুন → নিচে **Artifacts** সেকশনে **smart-alarm-apk** দেখবেন → ডাউনলোড করুন (zip ফাইল, ভিতরে APK থাকবে)

---

## ✅ ধাপ ৫: ফোনে ইনস্টল করুন (২ মিনিট)

1. ডাউনলোড হওয়া zip ফাইল থেকে `.apk` ফাইলটি এক্সট্র্যাক্ট করুন (ফোনের ফাইল ম্যানেজার দিয়ে)
2. APK-তে ট্যাপ করুন → **"Unknown sources থেকে ইনস্টল অনুমতি দিন"** চাইলে অনুমতি দিন
3. ইনস্টল সম্পন্ন!
4. অ্যাপ খুলে **Notification permission** এবং **Exact Alarm permission** অনুমতি দিন (Android Settings-এ চাইতে পারে)

## ⚠️ গুরুত্বপূর্ণ নোট
- **প্রথমবার বিল্ড**-এ GitHub Actions একটু সময় নিতে পারে (Android SDK ডাউনলোড হয় ক্লাউডে) — ধৈর্য ধরুন
- অ্যান্ড্রয়েড ফোনে "Battery Optimization"-এ MustWake অ্যাপকে **Unrestricted/No restriction** করে দিন, নাহলে Android নিজে থেকে অ্যালার্ম বন্ধ করে দিতে পারে ঘুমের মধ্যে
- ছবি-ম্যাচ ফিচারের জন্য ক্যামেরা পারমিশন দিতে হবে

## 🔴 কেন Spck প্রিভিউতে অ্যালার্ম বাজে না?

Spck Editor-এর "Preview" একটা সাধারণ **ব্রাউজার উইন্ডো**, আসল অ্যান্ড্রয়েড অ্যাপ না। এর মানে:

- `cordova-plugin-local-notification` (যেটা নির্দিষ্ট সময়ে অ্যালার্ম ট্রিগার করে, অ্যাপ বন্ধ থাকলেও) **শুধু আসল APK-তে কাজ করে**, প্রিভিউতে না
- তাই সময় সেট করে অপেক্ষা করলে প্রিভিউতে কখনো রিং হবে না

**সমাধান করা হয়েছে:** প্রতিটা অ্যালার্ম কার্ডে এখন একটা **"টেস্ট"** বাটন আছে — এতে চাপলে সাথে সাথে (সময় নির্বিশেষে) রিং স্ক্রিন, মিশন, এবং রিংটোন — সবকিছু প্রিভিউতেই টেস্ট করতে পারবেন।

**আসল সময়মতো অ্যালার্ম বাজানোর জন্য** GitHub Actions দিয়ে APK বিল্ড করে ফোনে ইনস্টল করাই একমাত্র উপায়।

## 🎙️ কাস্টম রিংটোন ও ভয়েস রেকর্ডিং

- **ফোন থেকে গান/গজল সিলেক্ট:** রিংটোন ড্রপডাউনে "📁 ফোন থেকে গান/গজল সিলেক্ট করুন" বেছে নিলে ফাইল পিকার খুলবে — সেখান থেকে যেকোনো অডিও ফাইল বেছে নিলে সেটাই অ্যালার্মের সাউন্ড হবে
- **নিজের ভয়েস রেকর্ড:** "🎙️ নিজের ভয়েস রেকর্ড করুন" সিলেক্ট করলে রেকর্ড বাটন আসবে — যেমন "ইয়াকিন, ঘুম থেকে ওঠো" বা "এখন পড়ার সময়" বলে রেকর্ড করলে সেটাই সেভ হয়ে অ্যালার্ম বাজার সময় প্লে হবে
- মাইক্রোফোন পারমিশন প্রথমবার চাইবে — অনুমতি দিতে হবে
- **নোট:** এই ফিচার আসল APK-তে ঠিকমতো কাজ করতে Android-এর `RECORD_AUDIO` পারমিশন লাগবে, যা `config.xml`-এ যোগ করা আছে
